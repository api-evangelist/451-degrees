# 451 Degrees

> 451 Degrees is a marketing-technology and ad-tech company founded in 2006 that builds Graffiti, a patented AI content ecosystem for digital content and ad-tech businesses. Graffiti uses machine learning, artificial intelligence, and natural language processing to analyze user-generated comments and digital content in real time, converting comment "noise" into structured data that powers brand safety, contextual relevancy, content recommendation, and first-party data strategies.

## Status for agents

- **No machine-readable contract.** No OpenAPI, Swagger, GraphQL SDL, AsyncAPI,
  Postman collection, or JSON Schema is published anywhere. Probed 2026-08-12.
- **No developer surface.** `api.`, `developer.`, `dev.`, `docs.`, `portal.`,
  `app.`, `mcp.`, `agent.`, `status.` under 451degrees.com are all NXDOMAIN.
- **No agent surface.** No MCP server, no A2A agent card, no `/.well-known/`
  documents of any kind, no llms.txt, no ai-plugin.json.
- **An API does exist, but it is sales-gated.** The company's own product page
  describes Graffiti as integrating "with simple API construction to current
  Comment Platforms and Ad Delivery Networks", and its investor one-sheet claims
  real-time APIs delivered to five ad delivery networks. None of that surface is
  publicly documented; the only route to it is the demo-request form.
- **Site is HTTP-only.** HTTPS on both www.451degrees.com and 451degrees.com
  fails certificate verification (self-signed cert). Treat any credential
  exchange with this origin as unprotected.
- The public site is a four-page WordPress install whose footer reads
  "© Copyright 2022", and the company's GitHub organization
  (https://github.com/451Degrees) has zero public repositories.

## Product

- [Graffiti](http://www.451degrees.com/product/): Real-time brand safety and
  contextual relevancy built by reading every comment on an article, product,
  image, video, or music file and converting it to structured data. Positioned as
  complementary to — not a replacement for — existing comment platforms, ad
  delivery networks, brand-safety vendors, and content-recommendation systems.
  Marketed as using no cookies, no mobile IDs, and no IDFA.
